# Liquidify 1.1.1 Beta 1

This beta brings the Liquidify patches and Liquidify Manager together in one release. It includes the latest Liquid Glass interface refinements, navigation and mini-player improvements, and optional Linn OpenHome output.

## Highlights

- Updated glass navigation, mini-player gestures, menus, sheets, and playback presentation.
- Improved patch selection and compatibility checks in Liquidify Manager.
- Linn renderer discovery and direct playback controls for compatible OpenHome devices. The renderer needs its own TIDAL login configured through Linn's app.

## Install

1. Download and install `Liquidify-Manager-1.1.1-beta.1.apk` from the assets below.
2. Open the Manager and download or import the supported stock TIDAL APK.
3. Select your patches, build the app, and install it. A differently signed existing installation may need to be removed first.

The patches require **TIDAL 2.200.0 (10004)** and **Android 13 or newer**. The Manager itself supports Android 7 or newer. Back up important data and signing keys before replacing an existing installation. `patches.zip` is available for custom imports; `SHA256SUMS` covers the release assets.

This is a beta: device-specific issues may occur. Linn behavior and hardware coverage have limits; see [Linn setup and validation](https://github.com/ninocss/liquidify/blob/main/LINN_OUTPUT.md). Please report reproducible issues in the repository.
